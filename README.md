# Chatku

Aplikasi pengirim pesan sederhana (simple messaging application).
Proyek CPK Praktikum Pemrograman Berbasis Platform: Frontend dan Backend.

## Teknologi
- Frontend: HTML, CSS murni, dan JavaScript murni
- Backend: PHP 8.4 murni dan MariaDB (library yang dipakai hanya JWT)

## Struktur
- `backend/` : server (PHP)
- `frontend/` : antarmuka (HTML, CSS, JS)
- `docs/` : dokumentasi dan catatan pengerjaan
